What NOVA can actually do

Every endpoint, capability and pattern is allow-listed. No invented features.

Core endpoints

Base: https://nova-ai-omega-lemon.vercel.app · Auth: x-nova-key: nova_pk_... for widget, Bearer for portal/admin.

POST/api/v1/widget/chat — customer chat (grounded, memory, behavior).
{"customerId":"visitor_123","messages":[{"role":"user","content":"Do you have size 42?"}]}
GET/api/v1/widget/config / /guide / /availability?days=14 — config, guide steps, ranked slots.
POST/api/v1/widget/transcribe — mic note → Whisper fallback if sidecar off.
{"audioBase64":"...","mimeType":"audio/webm"}
POST/api/portal/site/analyze — Portal learns site: fetches siteUrl, extracts products/FAQs, creates knowledge, builds guide. {siteUrl:"https://example.com"}
POST/api/v1/chat — integration chat (server-to-server).
GET/api/portal/* — knowledge, customers, chrono, voice, test chat (portal Bearer).
GET/api/admin/* — businesses, plans, flags (admin Bearer, super for plans).

How it works

Snippet → learn → guide → chat → schedule → voice. All via same brain.

Guide

Site analyzer → 6-step tour with pointer. Trigger: “guide me”.

guide.start

Knowledge

FAQ/product/policy/info/document. Bulk CSV/JSON, search preview.

knowledge.search

Chrono

Timezone, slot, buffer, hosts, overrides → ranked availability <1s.

booking.availability

Echo

Mic → transcribe (Whisper fallback) → TTS (OpenAI fallback) → handoff.

echo.transcribe
